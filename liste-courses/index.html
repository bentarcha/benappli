Mes courses

La liste de courses de la maison, partagée entre les téléphones.

Télécharger Voir dans la liste

L'application

Mes courses est un catalogue de produits courants, rangés par rayon : fruits et légumes, viandes et poissons, produits laitiers, pains et brioches, épicerie, surgelés, boissons, hygiène et entretien. Cochez un produit pour l'ajouter à la liste de courses, décochez-le une fois dans le panier. Vous pouvez aussi ajouter vos propres produits. Si vous le souhaitez, créez une « maison » et partagez son code : la liste est alors synchronisée entre les téléphones de la famille. Une fois installée, l'application apparaît sur le téléphone sous le nom « ListeCourses Maison ».

Aperçu

Ce que vous y trouverez

  • Un catalogue de produits courants classés par rayon
  • Ajout de vos propres produits, avec leur catégorie
  • Liste de courses : cochez pour ajouter, décochez ou videz en un geste
  • Partage de la liste à la famille avec un code de maison, facultatif
  • Fonctionne sans Internet : les changements sont envoyés au retour de la connexion
  • Trois thèmes de couleur au choix

Ce qu'il faut savoir

  • La liste est enregistrée sur le téléphone. Tant que vous ne créez pas ou ne rejoignez pas de « maison », rien ne la quitte.
  • Si vous utilisez une maison partagée, vos articles, le nom de la maison et son code sont enregistrés sur les serveurs Firebase de Google, pour être synchronisés entre les téléphones.
  • Le code de la maison permet de rejoindre la liste partagée : ne le donnez qu'à des personnes de confiance.
  • Aucune publicité, et aucun outil de mesure d'audience ni de rapport d'erreurs dans l'application.

Comment installer Mes courses sur Android ?

  1. Ouvrez cette page depuis votre téléphone et touchez Télécharger.
  2. Ouvrez le fichier téléchargé (notification, ou dossier Téléchargements).
  3. Si Android le demande, autorisez votre navigateur à installer des applications inconnues, puis touchez Installer.

Ces applications ne passent pas par le Play Store : Android ou Play Protect peut afficher un avertissement. Si vous avez téléchargé le fichier depuis cette page, vous pouvez poursuivre l'installation.
